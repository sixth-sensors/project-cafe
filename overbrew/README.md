## The front-end user platform for Homebrew

### Prerequisites

- [NodeJS and Node Package Manager (NPM)](https://nodejs.org/en/download)

### Setup

Install dependencies by running:

```
npm install
```

### Usage

To start the application, run:

```
npm run dev
```

You can format your code using:

```
npm run format
```

You can lint your code using:

```
npm run lint
```
